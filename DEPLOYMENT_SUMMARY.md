## 📋 Deployment Checklist

### Before Deploying

1. **Environment Variables** - Set these in Render dashboard:

   - `GEMINI_API_KEY` - Google Gemini API key
   - `YOUTUBE_API_KEY` - YouTube Data API key
   - `SERP_API_KEY` - SerpAPI key
   - `SENDER_EMAIL` - Email for sending newsletters
   - `SENDER_PASSWORD` - Gmail App Password (recommended)
   - `BASE_URL` - Your Render web service URL (e.g., `https://ai-news-web.onrender.com`)
   - `SECRET_KEY` - Auto-generated by Render (or set manually)

2. **Database** - PostgreSQL database will be auto-created by Render

3. **Services** - Two services will be created:
   - **Web Service** (`ai-news-web`) - Handles subscriptions and API endpoints
   - **Worker Service** (`ai-news-worker`) - Runs daily pipeline at 9am Nepal time

## 🚀 Deployment Steps

1. **Push to GitHub:**

   ```bash
   git add .
   git commit -m "Production ready - cleaned up code and configuration"
   git push origin main
   ```

2. **Deploy on Render:**

   - Connect GitHub repository to Render
   - Render will auto-detect `render.yaml` and create both services
   - Set environment variables in Render dashboard
   - Set `BASE_URL` to your web service URL

3. **Verify Deployment:**
   - Check web service is running
   - Test subscription form
   - Check worker service logs
   - Verify scheduled jobs run

## ⚙️ Key Features

- **Automated Daily Pipeline** - Runs at 9am Nepal time (3:15am UTC)
- **Welcome Emails** - New subscribers after 9am get today's news
- **Email Newsletter** - Daily AI news digest sent to all subscribers
- **Web Interface** - Simple subscription/unsubscribe form
- **Worker API** - Endpoints for transcription workers

## 📝 Notes
