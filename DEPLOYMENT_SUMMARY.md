## 📋 Deployment Checklist

### Before Deploying

1. **Environment Variables** - Set these in Render dashboard:

   - `GEMINI_API_KEY` - Google Gemini API key
   - `YOUTUBE_API_KEY` - YouTube Data API key
   - `SERP_API_KEY` - SerpAPI key
   - `SENDER_EMAIL` - Email for sending newsletters
   - `SENDER_PASSWORD` - Gmail App Password (recommended)
   - `BASE_URL` - Your Render web service URL (e.g., `https://ai-news-web.onrender.com`)
   - `CRON_SECRET` - Secret token for protecting internal endpoints
   - `SECRET_KEY` - Auto-generated by Render (or set manually)

2. **Database** - PostgreSQL database will be auto-created by Render

3. **Services** - One service will be created:
   - **Web Service** (`ai-news-web`) - Handles subscriptions, API endpoints, and pipeline execution
   - **GitHub Actions** - Schedules and triggers pipeline at 08:30 NPT and 09:00 NPT

## 🚀 Deployment Steps

1. **Push to GitHub:**

   ```bash
   git add .
   git commit -m "Production ready - cleaned up code and configuration"
   git push origin main
   ```

2. **Deploy on Render:**

   - Connect GitHub repository to Render
   - Render will auto-detect `render.yaml` and create web service
   - Set environment variables in Render dashboard
   - Set `BASE_URL` to your web service URL
   - Set `CRON_SECRET` (generate a secure random token)

3. **Configure GitHub Actions:**

   - Go to GitHub repository → Settings → Secrets and variables → Actions
   - Add secret: `CRON_SECRET` (same token as Render)
   - Add secret: `RENDER_BASE_URL` (your Render web service URL)
   - Verify workflow files exist:
     - `.github/workflows/trigger-preprocess.yml`
     - `.github/workflows/trigger-pipeline.yml`

4. **Verify Deployment:**
   - Check web service is running
   - Test subscription form
   - Check GitHub Actions workflow runs
   - Verify scheduled jobs execute at 08:30 NPT and 09:00 NPT

## ⚙️ Key Features

- **Automated Daily Pipeline** - Runs via GitHub Actions at 08:30 NPT (preprocess) and 09:00 NPT (pipeline)
- **Welcome Emails** - New subscribers after 9am get today's news
- **Email Newsletter** - Daily AI news digest sent to all subscribers
- **Web Interface** - Simple subscription/unsubscribe form
- **Worker API** - Endpoints for transcription workers
- **Internal Endpoints** - Token-protected endpoints for GitHub Actions triggers

## 📝 Notes

- **Scheduler:** GitHub Actions triggers at **08:30 NPT** (preprocess) and **09:00 NPT** (pipeline)
- **Architecture:** GitHub Actions → HTTP POST → Render Flask endpoints
- **Security:** Internal endpoints protected with `CRON_SECRET` token
- Free tier services may spin down after inactivity
- First request after spin-down may be slow
- Database connections are managed automatically by Render
