### ⚠️ Environment Variables Required

Set these in Render dashboard:

**Required:**

- `DATABASE_URL` - Auto-set from PostgreSQL database
- `GEMINI_API_KEY` - Google Gemini API key
- `YOUTUBE_API_KEY` - YouTube Data API key
- `SERP_API_KEY` - SerpAPI key (for transcriptions)
- `SENDER_EMAIL` - Email address for sending newsletters
- `SENDER_PASSWORD` - App password (Gmail App Password recommended)
- `BASE_URL` - Your Render web service URL (e.g., `https://ai-news-web.onrender.com`)
- `SECRET_KEY` - Auto-generated by Render (or set manually)

**Optional (with defaults):**

- `SMTP_SERVER` - Defaults to `smtp.gmail.com`
- `SMTP_PORT` - Defaults to `587`
- `FLASK_ENV` - Set to `production` in render.yaml
- `SCHEDULER_TIMEZONE` - Defaults to `UTC`
- `SCHEDULER_LOG_LEVEL` - Defaults to `INFO`

## Deployment Steps

1. **Push code to GitHub**

   ```bash
   git add .
   git commit -m "Production ready"
   git push origin main
   ```

2. **Create PostgreSQL Database on Render**

   - Dashboard → New → PostgreSQL
   - Name: `ai-news-db`
   - Plan: Free (or upgrade as needed)

3. **Create Web Service**

   - Dashboard → New → Web Service
   - Connect GitHub repository
   - Render will auto-detect `render.yaml`
   - Verify environment variables are set

4. **Create Worker Service**

   - Dashboard → New → Background Worker
   - Connect same repository
   - Render will auto-detect `render.yaml`
   - Verify environment variables are set

5. **Set BASE_URL**

   - In both services, set `BASE_URL` to your web service URL
   - Example: `https://ai-news-web.onrender.com`

6. **Verify Deployment**
   - Check web service is running
   - Check worker service is running
   - Test subscription form
   - Check logs for errors

## Troubleshooting

### Common Issues

1. **Database Connection Errors**

   - Verify `DATABASE_URL` is set correctly
   - Check database is running
   - Verify connection string format

2. **Email Sending Fails**

   - Verify `SENDER_EMAIL` and `SENDER_PASSWORD` are correct
   - For Gmail, use App Password (not regular password)
   - Check SMTP settings

3. **Scheduler Not Running**

   - Check worker service is running
   - Verify `SCHEDULER_TIMEZONE` is set
   - Check logs for scheduler errors

4. **API Key Errors**
   - Verify all API keys are set correctly
   - Check API key quotas/limits
   - Verify API keys are active

## Security Notes

- ✅ Secret key is auto-generated by Render
- ✅ Database credentials are managed by Render
- ✅ Environment variables are encrypted
- ⚠️ Never commit `.env` files
- ⚠️ Never commit API keys or passwords
- ⚠️ Use strong SECRET_KEY in production

## Performance Considerations

- Free tier Render services spin down after inactivity
- First request after spin-down may be slow
- Consider upgrading to paid tier for always-on service
- Database free tier has connection limits
